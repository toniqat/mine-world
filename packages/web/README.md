# @mine/web

Browser client. Vite + TypeScript + PixiJS (WebGL) for the board, plain DOM for the chrome. No framework.

## Controls

- Title: Start (or Enter) begins; with a save, Continue resumes and New game replaces the world.
- Drag / wheel / pinch: pan and zoom. WASD or arrows also pan. `H` returns to the main base.
- Click a base (Owned mine) to light it up and see its route; a disabled base (grey dot, struck through) also shows a bubble with its Repair button (a press anywhere else closes it and does nothing more). The main base (start cell, large diamond), the diamond button in the top-right capsule and `U` toggle the main-base panel, where it is levelled up (raising the pool cap) and the upgrades are bought; a press outside the panel closes it (and still acts).
- Points: every opened tile earns 1 and every new base 5, times the multiplier (1 + 0.1 per linked base, times the combo), into the pool (top centre). Once the pool reaches its cap nothing more opens until Cash Out moves it into credits (top right, next to the buttons).
- A new world is all fog; the first click places the main base there. Fogged tiles (dashed outline) cannot be opened or flagged; the main base sees 16 tiles, a base 9, and every opened cell 2 around it.
- Coloured tiles with a padlock are in a mining tier the mining technology (main-base panel, *Upgrades*) does not reach yet; levelling it up turns them into plain tiles. Opening one (or chording a number next to one) shows a bubble over it saying so.
- Classic mode: left-click opens, right-click or long-press cycles flag -> "?" -> clear (a "?" is only a note), clicking a number chords. Flags settle (become bases) on the next opening, never by themselves.
- Toggle mode (Settings): the flag button in the top-right capsule or `F` switches open/flag for taps.
- `Space` cashes out. `U` opens the main base. `Esc` closes.
- Touch devices (`device.ts`): tapping a number chords (as on PC), tapping a closed tile cycles flag -> "?" -> clear (the right-click cycle; a tap never opens a tile, except the first tap placing the main base), drag pans, two fingers pinch-zoom. No long press, no flag mode; Settings hides the input mode and long-press fields.
