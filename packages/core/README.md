# @mine/core

Pure game logic. No DOM, canvas or framework imports (spec INV-6). Consumed as TypeScript source by `web`, `sim` and the tests.

## Files

| File | Responsibility |
|---|---|
| `src/config.ts` | `GameConfig` and `DEFAULT_CONFIG` (spec §15). Every tunable lives here; `makeConfig()` merges partial overrides. |
| `src/key.ts` | Cell key encoding `(x, y) → number`, neighbour iteration, Chebyshev distance, `inDisc` (drone work area). East-west wrap (Earth mode): `wrapX` (canonical column), `deltaX` (shortest signed column offset); `forEachNeighbor` and `chebyshev` take the wrap width (0 = none). |
| `src/hash.ts` | `hash32` / `hash01` coordinate hash, value noise, fBm (§3.1). |
| `src/world.ts` | `World`: base layer + override layer + per-chunk density-debt pressure. `truth(x, y)` is the authoritative, stable mine assignment; `commit()` enforces INV-4. `setStart()` centres the mine-free start area on the first cell opened, i.e. the main base (locked once any truth is observed). With `startRelative` every noise / hash reads coordinates relative to the start, so the map around the main base does not depend on where it was placed (older saves: absolute). `terrain()` gives terrain walls (mountains: fBm blobs; rivers: fBm bands broken by fords) per 16×16 chunk cache, none before the start is set or within `terrainMinRadius`; a wall's truth is always 0. Legacy mine-band rivers only for old saves. Earth mode (`map`): `map` / `wrap` (the land mask and its width); terrain is water (and every row above or below the map) from the mask, always, with no procedural walls; noise is read at absolute coordinates; `truth`, `density` and `terrain` take any column; `distFromStart` measures across the seam. |
| `src/board.ts` | `Board`: player-visible cell states in 16×16 `Uint8Array` chunks (`CellState`: Unknown, Flag, Owned, Exploded, Lost, Mountain, Water, Revealed+n). Walls are never stored: `get()` asks the `terrain` hook (set by `Game` to `World.terrain`) for cells with nothing stored, so every Unknown check skips them. `isWall()`. `wrap` (set by `Game` to `World.wrap`): `get` / `set` accept any column and store it canonically; `forEachInRect` splits a rect across the seam and reports canonical cells once. |
| `src/fog.ts` | `Fog`: fog of war with fixed radii. `update(main, bases)` rasterises a disc for each new source (main base `mainRadius`, base `baseRadius`) into a per-chunk seen bitmap; `opened(x, y)` marks the `openedRadius` square around an opened cell. The seen set only grows; cells newly seen are collected for `take()`. Not saved: it follows from the sources (re-rasterised on load from bases and opened cells). Wraps like the board (`wrap`). |
| `src/csp.ts` | Constraint extraction per numbered cell, three modes (`engine` / `public` / `belief`, INV-1; walls are known safe in all of them), component BFS, region collection, scanner constraints (§4.1, §4.2, §6). Neighbours and keys wrap with `world.wrap`. |
| `src/solver.ts` | `solve()`: tiers T1a/T1b/T2a/T2b/T3/T4 with per-verdict tier attribution, density-weighted probabilities (§4.4), `enumerate()` backtracking with solution/node caps. |
| `src/resolve.ts` | Lazy resolution and intervention policies STRICT / FAIR / FORGIVING (§5); `rescue = false` (chords) never intervenes. An intervention commits an alternative solution of the whole component. FAIR never rescues when the flood fill touches a terrain wall (forced guesses against walls are intended). |
| `src/game.ts` | `Game`: online hooks (`online`, `cellOwner`, `mainBases`: false / -1 / none here, answered by `MirrorGame`) / east-west wrap (`wrap`, `wx`: every method takes any column; cells in events, keys and saves are canonical; neighbours, cascades, blasts, tiers and settlement centres measure across the seam) / fog of war (`fogged(x, y)`: a closed cell no source has seen, every closed cell before the start, when `cfg.fog.enabled`; the first `reveal` places the main base even on fog; reveal / flag / chord refuse fogged cells; every opened cell lifts the fog around it in `setCell`; `updateFog` registers the main base and new bases; `fog` is emitted with the lifted cells before `cells`) / mining tiers (`tierAt`: rings of `tiers.radii` around the main base, `miningTier` = 1 + the `mining` level, `locked`: reveal / flag / mark / chord refuse locked cells and cascades stop at them; each `mining` level emits `tech`) / "?" marks (`cycleMark`: Unknown -> flag -> "?" -> Unknown; `questions` / `questioned`, no game effect, dropped when the cell changes state, saved) / points (every cell an opening reveals earns `tilePoints` × the point multiplier into the unbanked pool) / full pool (`full()`: while the pool is at its cap, reveal and chord open nothing and return `full: true`; flags still work) / reveal / chord (one action, one turn; its reveals are never rescued, so a wrong flag lets the mine go off) / flag (never settles: its cells go to `deferred`, saved, and the next opening settles around them) / turns (every player action that changes tiles: an opening, a chord that opens something, placing a flag (`setFlag`; lifting one or flag -> "?" is not), ends with an `econ` event) / cash-out / buy (`streak_cap`, pushed into `Econ` by `applyUpgrades`) / bases (`baseInfo`, `upgradeMainBase`, `repairBase`, `repairCost`; rebuilt when a mine is owned, a base is disabled or repaired, or a cell stops being closed (opened, owned, lost, exploded; not a flag toggle) while bases exist; newly formed grand complexes are emitted as `grand` events) / tick / prestige / save. A hit sets off a blast (`explode`: radius from `blastRadius` for the mine's tier, every Owned mine inside is disabled, never the main base; every flag inside is lifted, and a flag on a mine goes off as `Exploded` and blasts in turn, only the first mine burning funds; what it shows is committed; `HitEvent.blast` with `disabled`, `cleared`, `chain`). Drones are not sold: `equipDrones(loadout)` is the hook for future equipment (`droneLoadout`: count, solver tiers, radius / speed levels, safe mode; saved). Scanner / probe / audit remain as core methods with a caller-given price but are not offered in the game. Settlement batches (§9), event emitter, log. Cascade reveals carry `CellChange.from` (the start cell) for the client's ripple. |
| `src/econ/income.ts` | `Econ`: credits, the unbanked pool (`unbanked`, at most `capacity`), streak (combo) multiplier (cap + `streakCapBonus`), `baseMult` (1 + `multPerBase` × active bases, set by `Bases`), `pointMult()` = bases × streak × prestige, `gain(points)` (× `pointMult`, clipped at the cap), `full()`, owned mines (`disabled` flag, prestige `dm`), settlement (`basePoints` per new base; wrong flags burn part of the pool), hits (burn part of the pool), cash-out, lifetime stats, prestige gain. |
| `src/econ/bases.ts` | `Bases`: every Owned mine is a base, the start cell is the main base. Bases produce nothing: every linked base raises the point multiplier (`weight`, `econ.baseMult`), and the main-base level raises the unbanked pool's cap (`capacity(level)` = `storageBase × storageGrowth^(level − 1)`, written to `econ.capacity`). **Disabled** bases (knocked out by a blast, `disabled`) are not bases at all until repaired: they do not count, are not in any complex, not linked. A base is **settled** (`settled`) when its 8 neighbours hold no Unknown or flag and every number among them has faded out; settled bases within 2 tiles (Chebyshev, chained) form a **complex** (`complexes`, `complexOf`), one network node: goods move inside it instantly and the main complex pays at once; an unsettled base is a complex of its own. **Grand complex** (≥ `grandMinBases` members): each member counts ×(1 + `grandBonusPerBase` × members) towards the multiplier (`grandBonus`, `Complex.bonus`); newly formed ones are listed in `formed` after a rebuild (never on the first one after construction / load). Network tree (parent: the complex reached by the shortest BFS path over `passable` cells, i.e. not Unknown or flagged; terrain walls count as opened, as they do for `settled`, among those whose hub is closer (Manhattan) to the main base; the edge `path` runs `exit` -> `entry`, preferring straight runs). A complex whose chain of parents does not reach the main complex is **isolated** (`isolated`): it does not count, not linked. `route()` / `routePaths()`, `pathAt` (point along a path), `info()` (`multShare`: what a base adds to the multiplier), `tick` (every linked complex sends one cosmetic shipment every `shipIntervalSec` on its own clock, phase from its hub; moves `shipments` edge by edge at `speed()` = `transportTilesPerSec`; animation only, they carry no credits), main-base level / upgrade cost. Older saves' undelivered goods are credited on load. On a wrapping world (`wrap`, from `Game`) complexes, the next-hop rule (`manhattan(a, b, w)`), BFS paths and grand-complex centres work across the seam; `pathAt(path, s, w)` keeps a seam step one tile long. `recompute()` rebuilds everything (called whenever bases change or a cell stops being closed while bases exist; flags do not count, the network treats them like Unknown) and writes `econ.baseMult` and `econ.capacity`; the stock of a complex whose hub was disabled is lost. |
| `src/econ/blast.ts` | Mine explosions: `blastRange(tier)` (`radiusByTier`, the last entry covering higher tiers), `blastRadius` (uniform in the range, hashed from seed / cell / hit count), `inBlast` (circle test), `repairCost(openedCells)` (`repairCostBase + repairCostPerTile × opened cells`). |
| `src/econ/upgrades.ts` | Upgrade definitions and price curves (§8, cut down): `streak_cap` (misc) and the mining technology (`tech`: levelled `mining`, max 4, priced by its `costs` table instead of `baseCost × growth^level`). Upgrades no longer sold are dropped from older saves; old one-shot `mining_t<n>` become `mining` level n − 1. |
| `src/econ/contamination.ts` | Audit / Audit+ (§10.3); not offered in the game at the moment. |
| `src/agents/drone.ts` | `DroneManager` (dormant until drones are equipped, see `Game.equipDrones`): belief-solver automation that stalls instead of guessing (INV-3), stall reports for triage, contamination basis. A drone stands on an Owned mine (auto-placed, draggable via `Game.placeDrone` / `holdDrone`) and works a disc around it. Phases: `extend` (line grows along `path` to the target, starting from `tip`, the cell the previous action left the line on, or from the anchor), `work` (`acc` fills, verdict re-checked, execute), `travel` (ride a line to another Owned mine within the radius of `home`). `linePath` builds the king-move path. |
| `src/events.ts` | Typed emitter. |
| `src/save.ts` | `SaveData` (structured-clone friendly; `questions`: "?" marks; `deferred`: cells whose flags wait for the next opening to settle; fog is not saved). |
| `src/maps/maps.ts` | Earth mode: `mapMask(id)` decodes a map's land mask once (`MapMask`: `w`, `h`, `data`, 1 = land; base64 through `multi/codec.ts`); `MapId` (`'earth'`). |
| `src/maps/earthData.ts` | Generated (do not edit): the Earth land mask, 1440 × 720 cells of 0.25° (equirectangular, column 0 at 180° W, row 0 at 90° N), from Natural Earth 1:50m land; continent outlines only (islands under 16 cells dropped, lakes under 16 cells filled); run lengths per row, LEB128, base64 (~17 kB). |
| `scripts/earth-mask.mjs` | Regenerates `earthData.ts`: `node packages/core/scripts/earth-mask.mjs [ne_50m_land.geojson]` (downloads the GeoJSON without a path). |
| `src/multi/protocol.ts` | Earth multiplayer, shared by server and client: `SIGNATURE_COLORS` (12), `MULTI` (fewer than 12 players per session, joins only below 90 % of the land opened, 10 min offline before a player leaves, the start square's radius, protocol version), `multiConfig(seed)` (Earth map, no fog / tiers / pool cap, no start-centred density), `PlayerInfo` (scoreboard row), `ClientMsg` (`hello.leave`: a kept seat to give up first) / `ServerMsg` / `WelcomeMsg`, `WireCells` (flattened x, y, state, owner, from). |
| `src/multi/session.ts` | `Session`: one multiplayer session, run by the server. One world and one board shared by up to `MULTI.maxPlayers` players (`SessionPlayer`: token, colour, score, main base, private flags, owned cells, deferred flags, online / last seen); `OwnerLayer` (owner per cell: colour + 1, chunked like the board). ## Key ideas

- **Truth is stable without commits.** Base values are stateless; debt pressure is frozen per chunk on first observation; overrides only change a cell once. So every revealed number stays valid forever and settlement can simply read `world.truth()`.
- **Constraints are derived on demand** from board state; a numbered cell with no hidden neighbours yields none (sealed). Active constraint count ∝ perimeter.
- **Three solver inputs**: engine (numbers + committed overrides), public (numbers only), belief (numbers + flags). Drones use belief (or public in safe mode); the player's probability overlay uses belief; the engine uses engine mode to decide whether a mine may be moved.
